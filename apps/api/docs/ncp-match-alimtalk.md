# 프리티풀 매칭 알림톡

채널: `@freetiful`. 운영 SENS의 승인 템플릿 `A0009`(사회자 답변), `A0003`(사회자 새 견적 요청), `A00051`(사회자에게 고객 답장)을 사용한다. 알림톡 실패 시 SMS 대체 발송은 하지 않는다.

## 검수 요청안

네이버클라우드 SENS > Biz Message > AlimTalk Template에서 기존 프로젝트와 `@freetiful` 채널을 선택한다. 아래는 기본형이며 광고 문구를 넣지 않는다.

| 코드 | 템플릿명 | 템플릿 승인 후 등록할 환경변수 |
| --- | --- | --- |
| `FT_MATCH_RECEIPT` | 고객_사회자섭외신청접수 | `NCP_MATCH_TEMPLATE_RECEIPT` |
| `FT_MATCH_UNREAD` | 고객_사회자답변미열람안내 | `NCP_MATCH_TEMPLATE_UNREAD` |
| `FT_MATCH_NO_REPLY` | 고객_사회자문의미답변안내 | `NCP_MATCH_TEMPLATE_NO_REPLY` |

**FT_MATCH_RECEIPT**

```text
#{고객명}님, 프리티풀에 요청하신 사회자 섭외 신청이 접수되었습니다.
신청 내용과 사회자의 답변은 프리티풀에서 확인하실 수 있습니다.
```

**FT_MATCH_UNREAD**

```text
#{고객명}님, 프리티풀에서 신청하신 사회자 섭외 문의에 아직 읽지 않은 답변이 있습니다.
프리티풀 채팅에서 답변을 확인하실 수 있습니다.
```

**FT_MATCH_NO_REPLY**

```text
#{고객명}님, 프리티풀에서 신청하신 사회자 섭외 문의에 마지막 답변을 읽으신 뒤 아직 답장을 보내지 않으셨습니다.
문의가 진행 중이면 프리티풀 채팅에서 이어서 답장하실 수 있습니다.
```

템플릿 조회 결과가 `ACTIVE` 및 `COMPLETE`인 경우에만 발송 가능하다. 미열람은 기본 1시간, 읽은 후 미답변은 기본 24시간이며, 발송 직전 상태와 알림 설정을 다시 확인한다. 예전 이벤트를 일괄 발송하지 않는다.
